## 💌 Sobre o projeto

Este projeto foi criado como um **presente de aniversário para uma amiga muito especial**. 💗

A ideia foi transformar algumas das nossas memórias e fotos em uma pequena experiência interativa na Web, criando uma página personalizada para celebrar a chegada dos **20 anos da Anna Luiza**.

> 🥳 **Bem-vinda à crise dos 20, Anna!**

Mais do que um exercício de programação, este projeto foi desenvolvido como uma forma de guardar e compartilhar um pedacinho da nossa amizade.

---

## 🎀 O que tem no site?

A página inicial apresenta um pequeno cartão personalizado com:

* 📸 Foto da Anna;
* 💕 Mensagem de aniversário;
* 🎂 Referência à chegada dos 20 anos;
* 🖱️ Botão interativo para acessar a galeria;
* ✨ Elementos visuais personalizados.

O projeto também possui uma **galeria de fotos**, organizada em uma grade para facilitar a visualização das memórias.

Ao clicar em uma fotografia, ela é aberta em um **modal de visualização**, permitindo navegar pelas imagens através das setas laterais.

---

## 📸 Galeria de memórias

A segunda página do projeto apresenta uma coleção de fotografias armazenadas na pasta `img/`.

As imagens são exibidas em formato de galeria e podem ser abertas individualmente.

Ao selecionar uma foto:

* 🔍 A imagem é ampliada;
* ◀️ É possível voltar para a foto anterior;
* ▶️ É possível avançar para a próxima foto;
* ❌ O modal pode ser fechado pelo botão de fechar;
* ⌨️ As teclas `←` e `→` também permitem navegar pelas fotos;
* ⎋ A tecla `Esc` fecha a visualização;
* 🖱️ Clicar fora da imagem também fecha o modal.

A navegação funciona de forma contínua: ao chegar à última foto, é possível voltar para a primeira, e vice-versa.

### 📄 Principais arquivos

**`index.html`**

Página inicial do projeto, contendo o cartão de aniversário e o botão para acessar a galeria.

**`index2.html`**

Página responsável pela exibição das fotografias em formato de galeria e pelo modal de visualização.

**`style.css`**

Arquivo responsável pela identidade visual, organização da galeria, responsividade, efeitos e estilização do modal.

**`main.js`**

Arquivo responsável pelas interações da galeria, incluindo abertura e fechamento do modal e navegação entre as fotografias.
