## 💌 Sobre o projeto

Este projeto foi criado como um **presente de aniversário para uma amiga muito especial**. 💗

A ideia foi transformar algumas das nossas memórias e fotos em uma pequena experiência interativa na Web, criando uma página personalizada para celebrar a chegada dos **20 anos da Anna Luiza**.

> 🥳 **Bem-vinda à crise dos 20, Anna!**

Mais do que um exercício de programação, este projeto foi desenvolvido como uma forma de guardar e compartilhar um pedacinho da nossa amizade.

---

## 🎀 O que tem no site?

A página inicial apresenta um pequeno cartão personalizado com:

* 📸 Foto da Anna;
* 💕 Mensagem de aniversário;
* 🎂 Referência à chegada dos 20 anos;
* 🖱️ Botão interativo;
* ✨ Elementos visuais personalizados.

O projeto também possui uma coleção de **fotos nossas**, armazenadas na pasta `img/`, tornando a experiência mais pessoal e especial.

---

## 📸 Nossas memórias

A pasta `img/` reúne as fotografias utilizadas no projeto.

```text
📁 img/
│
├── 📷 fotos da Anna
├── 📷 fotos nossas
├── 📷 momentos especiais
└── 📷 memórias
```

Cada imagem representa um momento compartilhado e faz parte da proposta de transformar o site em uma pequena lembrança digital da nossa amizade. 💕

## 💻 Como visualizar

O projeto não necessita de instalação de dependências.

Basta abrir o arquivo:

```text
index.html
```

em um navegador.

Também é possível utilizar o **Live Server** no Visual Studio Code para visualizar o projeto durante o desenvolvimento.
